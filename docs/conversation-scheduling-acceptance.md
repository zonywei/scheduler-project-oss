1. 无技术学科、无班主任/班主任性别的上传可以被识别；不自动补充这些字段。
2. 仅上传教师表时，作息与课时仍明确缺失；不得从 demo 或其它会话补齐。
3. 追问可在实际页面看到；回答可持久化并推动状态前进。
4. 任意未知或不支持的需求保留并追问；否定、例外、多条规则不得静默丢失，硬约束不得改成软约束。

7. 模型调用只发送必要匿名化上下文；未启用模型时明确说明实际能力。
8. 使用 synthetic 数据验证对话、持久化、确认、队列、CP-SAT 与输出；静态测试不代替端到端验收。
