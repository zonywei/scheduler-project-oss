# 通用中小学排课系统：目标与下一阶段建议

评估日期：2026-10-04。依据当前工作区及公开发布副本 `8886228` 的代码与测试源码；本次未重新验证生产部署，也未重新运行全量测试。

## 产品目标

产品主线是面向不同小学、初中、高中的排课系统：学校通过基础数据、作息和可组合规则表达差异，完成导入、排课、解释、调整和导出。通用优化内核可以保留为内部能力，产品验收围绕学校业务组织。

“个性化”分为三层：已支持规则的参数变化、已支持规则原语的组合、需要新增编译器的业务语义。前两层应尽量由学校自行配置；第三层必须明确不支持并进入开发流程，不能仅凭 AI 生成了 JSON 就显示为已支持。

## 推进顺序

### 第一阶段：三类学校的真实排课闭环

先覆盖小学、初中和高中行政班的单周循环课表。每类至少一套匿名场景，作息、学科、课时、教师跨班关系和个性化规则必须不同；另设一套故意冲突的输入。晚自习、值班和课后服务按学校配置启用。高中选科走班、跨校区与按日期变动排入后续阶段，仍保留在完整产品范围内。

建立“规则需求—结构化表达—编译器—测试—结果解释”的能力矩阵，并用场景差距决定开发顺序。既有 `SchoolProfile`、`SchoolProblem` 和适配器逐步成为实际输入链路；学校名称和实体名称不得承担业务主键或隐含策略。

验收要求：

- 同一套代码完成三类学校的导入、配置、求解和 Excel 导出；切换学校不修改 Python。
- 独立结果校验器确认硬约束违规数为零，检查课时完整、教师/班级/资源冲突；不能只相信求解状态。
- 故意冲突的输入给出可核查的规则或数据冲突说明；不自动降级硬规则。
- 记录模型构建时间、首个可行解时间、优化时间、软约束违规明细及规模；取得基线后再制定性能目标。

### 第二阶段：可组合的个性化规则

优先梳理有限、可组合的排课原语：禁排/固定、次数上下限、连堂/不连堂、间隔与分散、同步/错开、资源容量、条件联动、负担均衡和时间偏好。每项都包含作用对象、时间、硬软属性、优先级和例外；从现有成熟规则抽取，按编译器逐项迁移。

统一实体 ID 和规则能力注册信息；编辑器、AI 草案、服务端校验、编译追踪与结果解释消费同一事实源。先合并语义，再逐步淘汰重复实现。对于不适用当前模式、找不到对象或未编译的已启用规则，在求解前明确阻断或要求用户处理，不能只跳过。

采用明确的目标优先级，避免大量低优先级偏好压过更重要的软规则；例外及学校覆写必须能解释最终生效的规则。所有新增语义同时提供“应可行”“应无解”“软规则可违反但有代价”的测试。

### 第三阶段：教务可用的诊断和调课

建立规则到约束、约束到结果的证据链。无解时返回可核查的冲突集合与逐项放宽建议；有解时说明哪些偏好未满足及代价。未经证明，不把冲突集合称为最小冲突集。

调课允许锁定已确认课位、指定可调整范围，并把改动数量作为优化目标；发布前比较教师、班级和课位影响。用“临时请假后保住大部分原课表”的场景验收。

### 第四阶段：扩展时间与复杂教学组织

在前三阶段基础上推进 A/B 周、指定日期和考试周例外、专用教室与容量、跨校区通勤、高中选科走班。每项必须同时接入输入、规则、求解变量、独立结果校验和导出，不能只增加前端选项。

## AI 的位置与近期取舍

学校可以通过表单和规则模板独立完成支持范围内的排课，模型不可用时仍可工作。AI 负责澄清需求、绑定实体、生成受限规则和解释结果；以固定匿名语料评测否定、例外、硬软属性、作用范围和歧义拒答，不用换模型替代规则能力建设。

近期开发资源优先投入跨校输入、规则编译及端到端验收；跨行业扩展、继续堆单校开关、大规模视觉重做和计费功能不应挤占这一主线。

工程上应明确一个持续开发主线。当前私有工作区有大量未提交改动，公开仓库使用独立发布副本；下一轮实施前应选择性核对差异并以公开主线建立日常开发流程，真实学校数据独立保存，减少双目录手工同步造成的漂移。

## 建议下一项 Goal

在同一套代码和真实 Web/API 流程中，打通小学、初中、高中行政班三套匿名场景；学校差异由数据、Profile 和规则配置表达，完成导入—确认—求解—独立验课表—解释—导出，并建立可执行的规则覆盖矩阵。沿途修复阻碍该验收的模型、适配与编译缺口，保持现有功能回归通过。

此文为推进建议，不代表上述里程碑已实现。


## 用户业务边界补充（2026-10-04）

用户明确要求不以联合排课、白天、晚自习、周中或周末规定系统边界。上述三校场景用于验证配置能力，不形成固定业务模板；时间分类应是用户可选的配置。实际已完成的自定义时间格、周期课时及三校 API 验收见 [按业务定义排课问题](business_driven_scheduling.md)。任意周期、真实时间重叠、资源和可组合规则是接下来的主线。
