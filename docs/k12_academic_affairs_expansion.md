# K12 示例域教务能力扩展说明

> 本文档描述 K12 示例应用的领域能力。通用框架目标是支持 CP-SAT 可表达的多类运筹优化问题，K12 只是其中一个示例域。

本轮把系统从“排课规则工作台”继续推进到“通用 K12 教务配置中心”。新增能力集中在 `scheduler/app/academic_affairs.py`，Web 页面通过 `/api/academic-affairs` 自动读取 schema、指标、风险、建议和能力清单。

## 设计意义

- 先把中国 K12 学校常见的教务对象抽象成可配置表，而不是继续把需求写死到代码里。
- 风险检测先做跨表确定性校验，例如请假日志与已排任务冲突、场地同一时段重复占用、值守人数不足。
- Web 不再固定写死 6 个指标，而是根据后端 `metric_cards`、`recommendations`、`capability_items` 动态展示。
- 学校常见的 Excel/OA 表格流转进入半结构化闭环：导入先做未保存预览和风险重算，正式保存再写入可撤回变更台账，记录表级前后行数、责任来源和完整前后值；教师定位表和白天规则表也采用同一审计口径，当前表可下载 Excel/CSV 模板并导入预览，教务工作台也支持多 sheet 全量工作簿导入预览。
- 这些教务表多数仍先作为“数据入口 + 风险检查 + 决策建议”的前置治理层；教师请假是教务日志记录项，已审批/已确认请假会触发同年级同学科优先、非同年级同学科兜底的代课建议。确认代课教师后，如果代课教师与请假教师原课同节次撞课，系统会生成局部最小影响调课方案，只移动代课教师自己的冲突课，输出涉及教师变更前后课表并生成调整后的全局课表；不会自动写入硬禁排或触发全量重排。
- 普通课表变更不再只做日志记录：教务可在“课表微调沙盘”中选择已处理调课单，或直接填写班级、原星期/节次、新星期/节次、新学科和新教师。系统先预览同班换课/移课会影响的班级和教师课表，遇到新教师撞课时给出可选空课位，确认后生成新的全局课表文件并挂回当前结果预览。后续只把稳定、可复用的业务规则接入 OR-Tools 求解约束。
- 结果页围绕“当前可用课表”组织：课表数据驾驶舱用于看填充率、教师负荷、教师日负荷、连续课风险、班级课量、班级日课量、学科结构、星期和节次分布，并新增“规则影响解释”，从最终全局最优解 meta 指向的 `event_log.csv` 聚合软约束罚分、占比、主要涉及教师和处理建议，让教务直接理解当前课表为什么还有代价；教师负荷榜、教师日负荷榜、连续课风险榜、班级课量榜与班级日课量榜可直接点击抽查对应课表；教师日负荷偏高会生成教师日负荷均衡草稿，连续课风险会优先给出同班空课/自习课格或低冲突互换课位，常规上午/下午课只在常规课格内生成拆解建议，班级单日课量偏高时也会在同班已有教学活动的低负荷常规日课格寻找空课/自习课格，不自动挪到早自习或晚自习。结果页会把教师日负荷均衡、连续课拆解、班级日课量均衡等可执行项汇总成“微调建议队列”，按影响和可操作性排序并保证不同建议源前排露出，教务可一键带入课表微调沙盘预览。课表健康洞察把空课格、规则代价、教师总负荷跨度、教师单日课量、教师连续课、班级课量差异、班级单日课量、自习占比和局部调整历史翻译成教务动作，并用可点击的关联教师/班级标签帮助教务直接跳到对应课表抽查对象；课表版本时间线用于追踪原始求解课表、请假代课局部调整和人工微调之间的差异，方便教务在多轮调课后确认当前全局课表的来源。
- 复核/签核暂不作为本系统当前重点功能，避免把产品重心放到学校已有 OA/线下审批流程；本轮优先把排课规则、已排课表微调、已排课表统计和结果追踪做扎实。

## 验证

新增回归测试：

```powershell
pytest -q verification/fixes/tests/test_k12_academic_affairs_expansion.py
```

覆盖内容：

- schema 至少包含 26 张教务表。
- 能力清单固定为 50 项。
- 新增表归一化不会保留 `row_index`。
- Excel/CSV 模板导入不会自动持久化，正式保存会生成可撤回审计记录。
- 教师定位表和白天规则表保存会生成表级审计记录，撤回后恢复保存前的 Web 覆盖状态。
- 教师定位表模板导入会校验当前列名，缺列时拒绝导入，导入成功后仍需人工保存。
- 白天规则表模板导入会校验当前表列名，缺列时拒绝导入，导入成功后仍需人工保存。
- 教务全量工作簿会按 sheet 名匹配多张业务表，导入成功后仍只进入页面预览并重算风险。
- 场地冲突、教师请假冲突、容量超限、监考人数不足、值守人数不足、教师单日负荷均可被检测。
- 结果预览会返回课表统计、健康洞察、规则影响解释、教师日负荷、连续课风险、班级日课量、教师日负荷均衡/拆连课/班级日课量均衡微调草稿、微调建议队列和版本时间线，前端展示当前课表版本、调整批次、累计变动课格和关键课格差异。
